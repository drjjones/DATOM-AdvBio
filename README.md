# Advanced Biology

Interactive, unit by unit teaching site for Advanced Biology at Maret School, 2026-27. Ten units, fifty standards, each built around a model you can manipulate. It presents from a laptop or a tablet, works with a finger or a mouse, and keeps working offline after the first load.

Jordan Jones, PhD.

## Run it locally

```
npm install
npm run dev        # development server
npm run build      # production build in dist/
npm run preview    # serve the production build on http://localhost:4321
```

Set `SITE_BASE=/repository-name` when building for a GitHub Pages project site; the deploy workflow does this automatically.

## Content

`content/toc.json` holds the textbook's chapter and section structure and the course map. `content/standards/unitNN.json` holds the five content standards of each unit. Both are generated by `npm run extract` from the course's own planning documents, which live outside this repository, so the JSON is committed.

## Checks

`npm run lighthouse` audits every route type with the preview server running. `npm run screenshots` captures the pages at 1024x768 and 1920x1080 into `screenshots/`.
